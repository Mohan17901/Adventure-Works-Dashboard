AdventureWorks Sales Dashboard : A Comprehensive Power BI Project

I built a comprehensive sales dashboard for AdventureWorks, transforming raw data into actionable insights.

​Key features include:

1) Interactive KPIs: Tracked key metrics like Total Revenue, Profit, Orders, and Return Rate at a glance.

2)  Geographic Analysis: Visualized sales performance across continents and countries using an interactive map.

3)  Trend Forecasting: Monitored weekly and monthly sales trends to identify growth and seasonality.

4)  Dynamic What-If Analysis: Empowered business users to simulate the impact of price adjustments on profit.

5)  Robust Data Model: Designed a star schema with clean dimension and fact tables for scalable and efficient reporting.

​This project demonstrates my skills in data modeling, DAX, and creating interactive, user-centric dashboards.
